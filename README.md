# Digitaciones de instrumentos

App web para la clase de música: escalas, tablas de digitación y reproductor MIDI con la digitación de cada voz.

**Instrumentos:** violín, viola, violonchelo, guitarra, piano, flauta traversa, clarinete en Si♭, flauta dulce soprano (barroca), trompeta en Si♭ y trombón.

## Qué hace

- **Escalas:** escalas mayores, menores (natural, armónica, melódica) y arpegios, con la digitación de cada nota, pentagrama (en altura escrita para instrumentos transpositores) y reproducción a tempo.
- **Explorar notas:** diapasón interactivo (cuerdas) o tabla completa de digitaciones (vientos, guitarra, piano).
- **MIDI:** sube un archivo `.mid`, elige el instrumento de cada pista, cambia la velocidad (25–200 %), volumen por pista y general, silenciar/solo, transporte por octavas, vista de instrumento y/o partitura, y exporta un video (MP4 o WebM) con audio.

## Uso

Es un solo archivo, `index.html`, sin dependencias. Se puede abrir directamente en el navegador o publicar con GitHub Pages.

## Fuentes de las digitaciones

Clarinete (sistema Boehm) y flauta traversa: Woodwind Fingering Guide. Flauta dulce barroca: tabla de Dolmetsch. Trompeta y trombón: tablas estándar de pistones y posiciones de vara.
